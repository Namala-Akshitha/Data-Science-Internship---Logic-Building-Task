# Data Science Internship – Logic Building Task 1

## Overview
This repository contains my solutions for Task 1 of the Data Science Internship – February 2026. The assignment focuses on Python fundamentals, conditional statements, lists, loops, and string processing.

## Tasks Implemented
1. **User Login Check** – Validates username and password.
2. **Pass / Fail Analyzer** – Counts students who pass or fail based on the given marks.
3. **Simple Data Cleaner** – Removes extra whitespace and converts names to lowercase.
4. **Message Length Analyzer** – Calculates message lengths and identifies messages longer than 10 characters.
5. **Error Message Detector** – Counts error entries in system logs.

## Technologies Used
- Python 3

## How to Run
1. Clone or download this repository.
2. Ensure Python 3 is installed.
3. Open a terminal in the project folder.
4. Run:

   `python logic_building_task_1.py`
